# Omani Sailor — stars-only migration

The user has discontinued **all monetary rewards**. No baisa, cash, wallet, payout or teacher settlement feature is authorized.

- Mastery stars are earned from educational questions in the main app, up to 200 per phase; each 20 unlocks a badge.
- The Omani Sailor game requires 40 verified phase stars (second badge).
- Gems and chests inside the game provide **game points only**, separate from mastery stars. Treasure opening remains a visual game event.
- The existing archived 3D game has old monetary UI and is **not available to learners** until all such UI, storage and logic are removed and tested.
- The `boat-game` 2D prototype is now stars-only.
- No cash-based reward backend should be implemented.

Existing difficulty behavior (Easy/Medium/Hard), boat steering and island progression should be preserved during the 3D conversion. Keep the app's maintenance page enabled until acceptance tests pass.
