# Approved vocabulary image import

Upload **MEJ_4x4_16_384px_Equal_Crops.zip** to this folder without renaming it.
The workflow **Import Approved Vocabulary 4x4 Batch 01** verifies all 16 PNGs as 384×384, then installs the original full-resolution images into `assets/mej-az-approved-01/` and updates the application image bank and vocabulary review. Existing approved image banks and student data are preserved.

This folder contains no student or private data.
